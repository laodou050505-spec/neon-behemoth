# 《我是怪兽》Unity 场景搭建计划

工程：`/Users/ld/Documents/ChatGPT/MonsterCity`（Unity 6000.5.5f1 + URP + PICO SDK 6.0.0，设置从《刺猬的四季》复制）。
玩法原型：`/Users/ld/monster-city`（Three.js），设计文档：`游戏demo/我是怪兽/设计文档_v2.md`，风格参照：`游戏demo/我是怪兽/渲染图/01~03`。

## 原则

- **模块化**：每栋楼 = 地基层 + 若干标准层 + 顶层 + 附件，每层独立网格、独立碰撞体，枢轴在层底面中心。倒塌靠拆层，碎块用预制。
- **城市不限桌面**：按房间扫描结果，在桌面、柜顶、地板空地上各自铺城区。地板空地大时铺成整片街区（不只港口）。
- **一套模块拼所有关卡**：布局由程序按街区摆放（逻辑从原型移植），关卡只换布置、光照、追兵。
- **先场景、再玩法、最后 UI**；手的形象之后再定。

## 模块怎么做

楼的层模块要求严格对齐（尺寸、接缝），AI 生成的网格做不到，所以：

| 资产 | 做法 |
|---|---|
| 九种楼的层模块、楼顶、附件 | Blender 程序化建模（精确尺寸、封闭网格、UV 按开间重复），每种楼一套 |
| 立面 / 屋顶贴图 | Tripo nano banana 按渲染图风格生成单个开间的贴图，处理成可平铺，2K 图集 |
| 封印塔、电站、港口吊车、载具 | 结构复杂：先出参考图 → 分部件 → P2 白模 → 查破面 → 贴图；能程序化的部件程序化 |
| 碎块 | 每种层 3～4 块，Blender 从层模块切出来 |

## 步骤

1. 卡通着色器：三阶色带 + 背面外扩描边（按视距补偿）+ 窗灯自发光 + 烧焦参数。
2. 城市布局移植到 C#（城区 → 街区 → 地块 → 楼型 → 层数，边缘降高、过渡带）。
3. 第一版：用程序化方块模块搭出整城，和渲染图同机位对比，先把规模、天际线、配色、边缘过渡调对。
4. 逐个楼型换成 Blender 正式模块 + Tripo 贴图，每个楼型做完都和渲染图对比。
5. 封印塔、电站、港口、远景、路面细节（车、路灯、红绿灯、棕榈树）。
6. 头显里看一遍：近看不糊、没破面、描边不断；远看天际线有起伏、边缘自然；帧率稳定。
